# MISSÃO: ANÁLISE TÉCNICA E DOCUMENTAÇÃO COMPLETA DE INSTALAÇÃO E EXECUÇÃO DO WA TEST AGENT

## 1. Contexto e objetivo

Você está trabalhando dentro do repositório GitHub de um projeto de QA que contém um agente de inteligência artificial responsável pela execução de testes de Web Analytics (WA).

Esse agente é utilizado pelo time de QA para executar casos de teste relacionados à validação de eventos de Web Analytics em aplicações web.

Seu funcionamento envolve, entre outras atividades:

- Receber um relatório ou documento contendo as instruções de execução.
- Interpretar os casos de teste, cenários, eventos e respectivas propriedades e valores esperados.
- Identificar os ambientes que devem ser utilizados.
- Utilizar contas e credenciais de teste.
- Navegar pela aplicação e executar as ações descritas nos casos de teste.
- Identificar e validar os eventos de Web Analytics.
- Avaliar se os eventos e suas estruturas estão de acordo com os critérios esperados.
- Consolidar os resultados das validações.
- Gerar um PDF executivo contendo o resultado da execução e as respectivas evidências.

Atualmente, o agente está integrado ao projeto de automação Playwright e é acionado por meio do Gemini CLI.

O objetivo desta atividade é permitir que profissionais do time de WA, que não possuem familiaridade com ferramentas de desenvolvimento, consigam instalar, configurar e utilizar o agente em suas próprias máquinas corporativas.

Esses profissionais não necessariamente conhecem ferramentas como VS Code, Node.js, npm, Git, Playwright, MCP ou Gemini CLI.

Portanto, precisamos produzir uma documentação extremamente didática, detalhada e confiável, que explique todo o processo necessário para que uma pessoa consiga sair de uma máquina sem o ambiente configurado até conseguir executar o WA Test Agent com sucesso.

**IMPORTANTE: não assuma que as dependências são apenas Node.js, Playwright e Gemini CLI. Investigue o repositório e identifique todas as dependências reais e necessárias para o funcionamento do agente.**
