# OBJECTIVE

The solution consists of two main components:

### 1. Test Orchestrator

The Orchestrator:

* executes tests from the selected folders;
* collects failed tests;
* organizes and groups failures;
* creates batches of failures;
* prepares failure context for the healing process;
* facilitates local execution and maintenance of large test suites.

### 2. Playwright Test Healer

The Healer:

* investigates test failures;
* uses Playwright/MCP and available execution evidence;
* analyzes the test and project context;
* identifies the probable root cause;
* proposes a correction;
* generates a patch/proposal;
* keeps a Human-in-the-Loop before changes are applied;
* validates the solution after the change.

The presentation must clearly show that the **Orchestrator and Healer are connected but have different responsibilities**.
